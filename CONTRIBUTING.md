# Contributing

Contributions are welcome through focused pull requests.

1. Open an issue before changing a public command, receipt schema, Git/GitHub mutation, or authority boundary.
2. Keep one active lifecycle path; do not add compatibility aliases, one-shot execution, implicit merge behavior, or hidden recovery.
3. Add focused tests for every new failure boundary.
4. Run `npm run check` and include the exact result in the pull request.
5. Keep challenge-extension code and other differently licensed Wornpage repositories out of this AGPL source tree.

By contributing, you agree that your contribution is licensed under AGPL-3.0-only.
