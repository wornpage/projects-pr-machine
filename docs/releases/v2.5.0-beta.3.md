# Wornpage PR Machine 2.5.0-beta.3

This package uses Wornpage attribution in the public and packaged README. Controller behavior, public APIs, dependencies, and the AGPL-3.0-only license are unchanged.

Install the current package:

```sh
npm install --global https://github.com/wornpage/projects-pr-machine/releases/download/v2.5.0-beta.3/wornpage-projects-pr-2.5.0-beta.3.tgz
projects-pr --help
```

The release includes the package and its SHA-256 checksum. Earlier versioned releases retain their original contents.
